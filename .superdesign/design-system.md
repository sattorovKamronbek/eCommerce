# Implemented source design system

Refreshed 2026-11-11 after the marketplace redesign. This records current source, not approval of new business/backend behavior. **ORO** remains temporary and configured in `src/lib/config.ts`; page wordmarks use Cormorant text with translate="no". Customer copy stays in `src/messages`, including localized `editTitle`, `editIntro` and `typeNavigation`; marketplace uz/ru/en and legacy Uzbek remain. UZS prices are development samples.

- Stack: Next 16.4.6 App Router/React 19.3, strict TypeScript; Server Components with small client navigation/theme/browser-cart islands; Tailwind 4, shadcn new-york/Radix/CVA, Lucide.
- Style isolation: `src/app/globals.css` now contains base/legacy foundations only. Marketplace locale layout additionally imports `src/components/marketplace/styles.css`; all new rules are scoped to `.mp`. Legacy layout does not import marketplace CSS.
- Light palette: background #f7f8fa, ink #11151a, white cards, muted #535d69, border #d6dbe1, input #a9b2bf. Dark: #11151a/#f7f8fa, cards #1b2129, muted #c2c9d2, border #3b4552, input #606b79. Lime primary/highlight #d0f36b. Focus #637c28 light/lime dark. CS2 system preference intentionally uses dark independently of OS preference; explicit light stays light.
- Type: local DM Sans 400/500/600/700; marketplace headings 700, -0.05em/1.06. Home 48–86px/1.02 with muted second line, catalog 48–88px, detail 36–60px; sample headings 22–31px; tabular prices 20–27px. Body 16px/1.55. Cormorant wordmark 60px, -4px; legacy serif display remains.
- Editorial composition: sidebarless header with centered underline navigation, lime locale state and native theme control; restrained development strip. Desktop home puts headline/actions left and staggered two-image destination pair right (second card offset 36px), then three-item sample edit. Catalog adds heading/intro, type-navigation underline, open filter row, sample grid and trading boundary. Detail separates image, description, sample-price block and demo sizes.
- Shared cards: `src/components/marketplace/sample-card.tsx` renders exactly one accessible Link around image/copy/action; home uses h3 under its edit h2, catalogs h2. Open layout, 6px image corners and top-bordered price/action row. No invented seller/ratings/stock information.
- Geometry: max 1680px and 3.6% gutter; sample grid 26px gap; destination/detail media 7px, sample media 6px, actions/controls/boundary 5px, locale/size 4px. Marketplace --radius 0.375rem; global literal Tailwind radius aliases remain 0. No custom marketplace shadow.
- Responsive: <=1000px hero text stacks above two destination cards (24px stagger); <=800px header navigation wraps, samples 3→2, filters 4→2 and detail stacks; <=600px samples become one column, destination pair remains two columns, 18px gutter. Theme native selector width 124px/120px <=520px.
- Navigation: `sampleFilterQuery` URL-encodes q/type/sort, trims/caps q to 100 chars and omits featured default. Type navigation preserves search/sort; sample links forward filter context to detail; detail return link restores it; locale links preserve current query. Filters stay native GET forms with no sidebar/client store.
- Accessibility: one link per card/destination, minimum 44px header/locale targets and 46–52px controls; visible focus/skip link with focusable main target; localized aria navigation; tabular prices; reduced-motion disables hover transforms/transitions.
- Preservation: warm legacy #f8f7f4/#262b24 with rust #9a5335; serif editorial display, square geometry, retained `/storefront-preview`, catalog/detail/cart/wishlist/info routes and existing browser storage IDs. Marketplace sample IDs remain outside the browser cart.
- Assets/boundaries: four existing marketplace illustrations rifle/knife/puffer/overshirt reused across six explicitly qualified development samples. Home edit selects violet-rifle, steel-knife and sand-overshirt. Keep development, illustration, not-for-sale and UZS-price qualifications visible. No live accounts, orders, payments, delivery, seller metrics or Steam integration. Browser cart totals remain estimates; custody/payment/commission/payout/seller rules remain unresolved.

Exact tokens/full CSS: `.superdesign/init/theme.md`. Complete primitives/shared SampleCard: `components.md`; roots/shells: `layouts.md`; complete source candidates including both CSS files: `pages.md`; routes/query helper and extraction menu: `routes.md`, `extractable-components.md`.
