# Marketplace catalog redesign

The owner approved `docs/design/2026-11-16/catalog-directions.png` as the visual
direction on 2026-11-16. CS2 uses a compact, technical catalog; clothing uses a
quieter editorial presentation. Both retain light, dark and system theme choices.
The generated counts, ratings, products, filters and prices are illustrative and
are not authorized data or features. The actual application continues to use
its three labeled sample items per ecosystem and its working search, type and
sort controls. The original storefront and account authorization remain intact.

The owner separately requested more information on the home page about how the
store will work, its sellers and products. While the new home concept still needs
revision, add an explanatory section in the existing design using the already
localized buying-and-selling copy and a link to the full information page.

Use the existing Next.js Server Components and marketplace styles. The desktop
catalog has a heading, type shortcuts, left-side filter controls and sample grid;
on smaller screens controls stack above the grid. CS2 is visually denser, while
fashion uses calmer type and larger imagery. Preserve existing copy, links,
locales, keyboard access, contrast and theme persistence. Never imply that
samples represent real stock, ratings, purchases or Steam ownership.
